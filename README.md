# 红楼梦研读（演示版）

在线阅读：https://huuduch517-dev.github.io/hongloumeng/

一个纯静态的《红楼梦》研读网站，用来展示这套“导师式研读”的结构。演示版收第 1–8 回。

## 有什么

- **原文与脂砚斋批语**：逐段排版，批语以角标形式点开。
- **白话译文**：贴原文直译，一句对一句。
- **讲解（导师模式）**：多数旁批先停在一句原文、问一个问题，读者可以先写下自己的想法，再展开看解读、“怎么看出来的”和可信度标注。
- **读法库**：抠措辞、看位置、找对不上的地方等十几种读法，自动汇总每种读法在各回练过的地方。
- **欧丽娟怎么读**：把台大欧丽娟教授《红楼梦》课程的观点按回、按人物转述出来（附视频时间点），和本站的读法对照，并标出分歧。
- **词条库、人物、关系图、我的笔记**：笔记存在读者自己的浏览器里。

## 内容来源

- 原文、脂批与脂本原有的通灵玉、金锁图式为古籍。
- 讲解、译文、词条库、读法库、“欧丽娟怎么读”的转述与评析为本项目自写。
- 演示版**未收**出版社版本的注释、书影与插画。

## 本地打开

纯 HTML + JS，无需构建。在本目录运行 `python -m http.server`，浏览器访问 `http://localhost:8000`。
